# projectZED

**Before I Walk** is a browser-based senior-year planner with a graduation countdown, bucket list, and progress summary. The **Job hunt** page adds a private application tracker for company, role, application status, follow-up dates, and notes, with search, status filters, and a quick stats dashboard.

Open `index.html` to start. Use the navigation to switch between the senior-year dashboard and the job application tracker. Information is saved in the browser's local storage and is not sent to a server.

Ideas for future upgrades:
- Add interview dates with reminders and a prep checklist.
- Track salary ranges, job links, recruiter contacts, and resume versions.
- Add a simple application pipeline or weekly application goal.
- Let users export a backup of their applications as a CSV file.
